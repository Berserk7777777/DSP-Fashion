# 同时自适应剪枝时点与保留数量：研究原型

此版本实现用户要求的两项自适应：首次实际剪枝也可以改变时点，保留数不限定为预写的3/4分支。代码只在明确评分时访问当前任务存活候选的Personal。尚未进行新增真实轨迹效果评估，不能声称Personal或最优seed命中率提升。

## 决策逻辑

1. 固定原始8seed和28步调度，累计去噪预算严格112，保留至少2个候选到终点再评分选1。两候选下限是一项明确的设计约束，不是理论最优结论。
2. 第一次评分在第5步初始化，**不是第5步强制剪枝**。初始最迟可剪时点为9；初始化取该期限的一半向上取整。此前没有任何任务内Personal信息，因此不把首次评分本身称为由Personal自适应选择。
3. 三个**实际连续且均已评分**的step才建立稳定性证据。固定本步领先者身份，计算其在这三步相对各候选的分差；三次均为正且均值严格大于两倍样本标准差，则该候选标记可剪。跳过评分后，三个稀疏观察不能冒充三个连续step。该判据是启发式，不能解释为统计置信区间或终值胜出概率。
4. 提议移除可剪者，再把保留数投影到预算可行的整数区间。优先剪稳定落后者；必须额外减少数量时，按当前Personal从低到高强制剪枝并记录`budget_forced`。预算要求保留更多候选时，可剪者也会暂留。相同Personal保留较小的原始seed。
5. 不足三步证据或本次没有实际剪枝，就下一步再评分。实际剪枝后，使用已观察到的分差变化估计最近的线性交叉时间，在交叉时间一半与预算最迟节点前两步中取更早者，再次评分。这只是调度启发式；提前两步给重建连续三步窗口留空间。评分的决定在读取该step的Personal之前完成。
6. 任一步如果继续保留当前数量会破坏恰好112的可行性，立即安排评分并按上述规则剪枝。只剩两个候选时不再中间评分，到28步用实际终值选1；被剪seed永不复活。

初始化位置、半交叉触发和至少两个终点候选均为预先声明的研究设计，未经独立验证，不宣称免参数或最优。没有旧DP经验风险表、训练预测器或测试集选参入口。

## 预算为何严格成立

当前已完成`t`步，已花费`C`，还有`h=28-t`步。若本步后保留`k`个，未来下一步必须先推进这`k`个，之后允许继续单调剪枝，但至少2个走到终点。未来去噪总量可达的整数区间恰好为：

`k + 2(h-1) <= 112-C <= k*h`。

控制器每次只从满足此式的保留数中选择；终点断言`C=112`。这只是算力可行性，不包含Personal风险估计。合成测试以小规模所有单调人口序列穷举核验该区间。

在尚未剪枝的初始阶段，要保留至少两个终点候选，有`8*t+2*(28-t)<=112`，因此首次剪枝最迟为第9步。这个限制来自预算；即使第9步排名仍不可靠，也无法无限等待。记录强制剪枝可以暴露这个难点，不能消除它。

## 评估开销的明确限制

默认PSP评分为8+4+2=14张候选图。此版本保留连续三步判据，首次对8seed建立证据就需24张；之后还需额外评分。因此**当前版本不满足接近14次评估的理想目标**，只作为同时自适应时点/数量的可审查原型。

可以少做中间去噪步的解码，但不能免费获得那些步的Personal。若要进一步逼近14次，需要另行研究部分候选评分、廉价触发信号或独立数据训练的终值排序器，不能将未评分Personal当作可见输入。

去噪112相同不代表端到端总计算量或耗时相同。在线输出另外保存候选评分图数、评分轮数、CLIP补齐到4后的实际批次数/槽数与总耗时；策略CPU计算和阶段耗时尚未做真实GPU测量。

## 实现与验证

- 核心：`fashion_psp/search/fully_adaptive_psp.py`，预算合法性、观察计划与剪枝共用同一控制器。
- 在线入口：`python -m fashion_psp.experiments.run_dualfashion_fitb_fully_adaptive`，接入现有模型及逐步断点，输出单独目录。没有启动2207任务推理。
- 冻结记录：`fashion_psp/artifacts/fully_adaptive_psp_v1/frozen_rule.json`；源码哈希不匹配会拒绝在线启动。
- 合成例子：`python -m fashion_psp.experiments.inspect_fully_adaptive_synthetic`。例子只验证控制行为和资源核算，不能衡量真实Personal效果。
- 测试：`python -m unittest fashion_psp.experiments.test_fully_adaptive_psp -v`，含穷举可达性、首剪时点与数量变化、观察时点变化、因果未评分数据投毒、强制剪枝、迟发最优反例及在线断点恢复。

本200任务仍属于已研究测试子集，不继续回放不同新规则来筛选胜出方法。当前只做合成验证和1任务PrepareOnly配置检查；未读取其真实Personal轨迹评估本策略，也未报告新命中率。
